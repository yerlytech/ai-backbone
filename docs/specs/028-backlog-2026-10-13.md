# 028 — The backlog of 2026-10-13, as one batch

## What

The ten open lines of `docs/backlog.md` on 2026-10-13 are built in one
attended cloud session, reviewed, and carried through the gate as one version
(3.37.0, a minor: an argument and two layer recipes are new). The backlog is
empty when it lands.

## Why

The maintainer asked for it on 2026-10-13 ("toplu spec ile hepsini
kapatabiliriz"). Six lines come from projects and stop a person on day one
(a new project in a folder they made, the first save after `just stack rust`,
the first build); three are small and need no measurement but their own.

## The lines this spec takes

1. n-9d7b12, `just new-project` takes a folder that exists and is empty (or
   holds only `.DS_Store`), the common case when the person made the folder
   and opened it in the editor first.
2. n-343ebd, `just ref-add <file>.bundle` clones a git bundle into
   `.references/`, listed as local only, with where it came from.
3. n-320c61, `just ref-add <folder> "why" live` lists a folder where it
   stands (`url = ""`, `path`, `status = "live"`), never cloned, which
   `ref-fetch` already reads.
4. n-ae6ffe, `just stack <lang>` adds the ignore lines the layer names (a
   `_gitignore` recipe in it; the Rust layer's says `target/` and `*.rs.bk`)
   to `.gitignore`, each once.
5. n-9072c4, the Rust layer's `lint` and `test` say "no Cargo.toml yet" and
   pass when the workspace has none, so the first save after `just stack
   rust` is not blocked.
6. n-dc6e02, `just release` moves the manifest's version through the layer's
   `_set-version`, which the Rust layer has had since spec 016; a layer copied
   before it has none. Release and doctor now say so when a manifest is there
   and the layer cannot move it, naming where to copy the recipe from.
7. n-e7086a, `session-start` writes the folders `just`, `prek`, `graphify`
   and `uv` live in to the file Claude Code names in `CLAUDE_ENV_FILE`, so
   the agent's Bash finds them after a `/resume` too (claude-code 2.1.295,
   read in its CHANGELOG on 2026-10-13).
8. n-bdb802, `just doctor` says when the SessionStart hook has never run on
   this machine (session-start leaves a stamp), and names `claude --debug`,
   which logs each hook's command, outcome and time (2.1.296).
9. n-3dce3e, the session skill: when auto mode blocks a deletion the owner
   approved, ask them to type the command in the chat; never offer a `!`
   line, which runs nothing in the VS Code extension.
10. n-335237, the Rust layer notices a workspace that moved since its last
    build (a stamp in `.git`, per clone) and cleans the workspace's own
    crates, never the dependencies, before it builds; `just clean-own` does
    it by hand.

## Not doing

- Moving a version in a manifest from the core: the layer knows its manifest.
- Running Claude Code itself here: the env file is checked by what the recipe
  writes, and the hook by its stamp.
