# 026 — The backlog of 2026-10-06, as one batch

## What

Every open line of `docs/backlog.md` (27 on 2026-10-06) is built, or answered
on the spot, in one attended cloud session, reviewed, and carried through the
gate as one version (3.33.0, a minor: new recipes, new examples, new optional
arguments). The backlog is empty when it lands.

The maintainer asked on 2026-10-06: "tüm açıkları tek seferde
kapatabilirsek kapatalım" (close every open one in one go, if we can). The
unattended run takes one line a night, oldest first; 27 nights is a month for
lines most of which are a paragraph of text or a dozen lines of shell.

## Not doing

- Telling which agent session wrote which file (n-afdf1d's second half):
  git does not know, and a guess would be wrong exactly when two sessions
  share a tree. The save lists what it takes (it did) and, with paths, what
  it left. Nor is a path-limited save safe while another session writes in
  the tree: prek sets the other files aside during the checks (found in
  review, prek 0.5.5), and the recipe's comment says so.
- A default nice level or job cap: a build server wants every core. The
  setting is per machine, off until set.
- Running a launchd job, Docker or ghcr.io from this sandbox: no Mac, no
  Docker daemon. The suite checks what the recipes write and refuse; the
  first real run is the measurement, as for `ci-flutter.yml`.
- Spec 020's last line (a real Windows machine): still open.
