# NNNN — Title

**Status:** accepted
**Date:** YYYY-MM-DD
**Relates to:** the ADRs this one builds on, amends or replaces, by number. "None" if
it stands alone. A decision that quietly reverses an earlier one, without the earlier
one saying so, is how a rulebook stops being one.
**Measured on:** what the claims below were checked against — the thing, its version
and the date: "<thing> <version>, YYYY-MM-DD". "Nothing" only when nothing below
says what a tool or a version does (a name, a folder, a rule for people), and then
say that. "From memory" is never the reason: a claim that was not measured is
measured first, or taken out. A version an agent remembers is a version that has
moved on.
